CNN Based Computer Vision Prototype
Introduction

This project focuses on building a Convolutional Neural Network (CNN) based computer vision prototype using an image dataset. The objective is to classify images into different categories using deep learning techniques.

The project demonstrates how CNNs learn visual patterns using:

Convolution layers
Activation functions
Pooling layers
Dense layers
Feature extraction
